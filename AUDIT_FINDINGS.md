## Deliberately not changed

- `minSdk` stays 24 (owner decision, 2026-11-05): raising it to 30 would fully close task hijacking (F58) but drop Android 7–10 users. The app-side mitigation in F58 stays; don't raise `minSdk` for this reason without asking the owner.
- Smart titles ("Receipt from …") and suggested tags stay English (owner decision, 2026-10-31, closes R11): they are stored
  document data and search tags, so one language keeps search and folders consistent across language changes.
- Documents and database encryption at rest (R20, owner decision 2026-11-08): skipped. Documents, OCR text and the database rely on Android's file-based encryption and the app sandbox. Encrypting with Android Keystore/SQLCipher/Tink AEAD adds key-loss risk and runtime performance penalty; app lock (`FLAG_SECURE`, biometric/device credential) provides sufficient protection.
- Exported activity internal actions (R21, owner decision 2026-11-08): skipped as low risk. The exported activity accepts internal actions (open document, recycle bin, settings, unsaved scans, scan) from external intents, but they only navigate and only execute after device/app unlock.
- Crash reports file names (R22, owner decision 2026-11-08): skipped as low risk. Crash reports are strictly local on-device and never leave the device unless explicitly shared by the user.
- Debug screenshot allowance (owner decision 2026-11-08): `MainActivity` skips `FLAG_SECURE` only when `BuildConfig.DEBUG`, allowing screen recording and UI screenshot testing while locked; release builds strictly enforce `FLAG_SECURE`.
- Mechanical translations check (completed 2026-11-08): all 5 non-English languages (Hindi, Telugu, Kannada, Tamil, Malayalam) contain 100% of the 1,354 strings with exact matching placeholders to English; native speaker review will assess tone and nuance prior to store launch.
- OpenCV Java wrappers (generated from upstream by `scripts/opencv`).
- OpenCV 5.0 upgrade (major version, needs native rebuild).
- IDE-only style hints and false positives (argument order, "unused" symbols that are used).
- "Tips" notifications (low value, nag risk).
- Root or emulator detection, anti-tamper and Play Integrity: they need network access (offline-first rule), are routinely bypassed and would not protect data on a compromised phone; R20 (encryption at rest) is the meaningful step.
