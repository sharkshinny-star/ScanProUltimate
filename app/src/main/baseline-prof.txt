# ScanPro's own startup and hot paths. Android compiles these ahead of time when the app is installed (from Play
# or through androidx.profileinstaller), so the first launch, the camera and the document screen don't start
# out interpreted. Wildcards are expanded against the app's classes before R8, so the rules survive renaming.
#
# A measured profile can be added on top: run the :baselineprofile generator on a device
# (./gradlew :app:generateReleaseBaselineProfile); its output is merged with these rules.
#
# HSP = hot, run at startup, run after startup.  L = load the class early.
